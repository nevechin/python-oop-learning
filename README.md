# Python OOP Practice

A small Python project created while learning Object-Oriented Programming.

## Concepts Learned

- Classes and objects
- __init__ and self
- Instance attributes
- Inheritance
- Method overriding
- Composition
- Encapsulation
- Working with external modules
- Basic GUI drawing with turtle

## Project

The program generates a random rectangle and allows the user
to guess a point and the rectangle's area.

## Learning Note

This project is based on an existing OOP learning exercise.
I modified and experimented with the original implementation
while learning Python OOP.
